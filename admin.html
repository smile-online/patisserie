أول مرة؟ إزاي أجيب المفتاح
  1. افتح صفحة إنشاء مفتاح جديد وانت داخل بحساب GitHub.
  2. Token name: اكتب smile-admin — و Expiration: اختار مدة طويلة (سنة).
  3. Resource owner: اختار smile-online.
  4. Repository access: اختار Only select repositories وحدد patisserie.
  5. في Permissions ← Repository permissions ← Contents اختار Read and write.
  6. دوس Generate token، انسخ المفتاح والصقه فوق.

المفتاح بيتحفظ على الجهاز ده بس، ومحدش يقدر يعدّل من غيره. لو موبايلك ضاع، امسحه من نفس الصفحة على GitHub.
